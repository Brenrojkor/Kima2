# Kima Web App

This repository contains the development of a web application for a Costa Rican company called **R.A. Costa Rica**, created as part of the *Requirements Analysis and Modeling*, *Systems Design and Development*, and *Systems Implementation* courses. The project seeks to centralize and automate key processes, such as document organization, project tracking through tickets, and automatic file conversion, significantly improving task control and resource management efficiency. Additionally, it will offer management modules for clients, products, reports, and roles, with an innovative approach that will integrate all these functions into a single software package.
This project aims to improve **RA Costa Rica's** productivity, reduce errors, streamline projects, and provide a scalable solution adaptable to its growth.

## 📑 Main Features

- **Announcements**: Module for publishing internal or external communications, facilitating communication between the company's different users.
- **Contacts**: Space to record, organize, and consult information about relevant contacts (suppliers, collaborators, strategic allies).
- **Clients**: Comprehensive management of the client base, with updated data to improve project support and follow-up.
- **Tickets**: Incident and request tracking system, enabling project traceability and ensuring better task control.
- **Quotation**: Tool for preparing and controlling quotes, streamlining negotiation and sales processes.
- **Requirements**: Recording and controlling client or internal project requirements, ensuring they are met within the workflow.
- **Price List**: Managing product and service price lists, keeping information up-to-date for quotes and estimates.
- **Users**: User and role management within the system, ensuring security, access control, and feature customization.

## 🛠️ Technologies Used

- **Frontend**: CSS, HTML, JavaScript, SCSS
- **Backend**: PHP
- **Database**: Microsoft SQL Server
- **Version Control**: Git
